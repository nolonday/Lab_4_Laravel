# Учебный сайт на Laravel

Учебный проект по серверной веб-разработке. В лабораторной работе изучается работа с моделями Eloquent, миграциями базы данных, фабриками и заполнением таблиц тестовыми данными.

## Реализовано

- Модель `Article` для работы с новостями.
- Миграция таблицы `articles` с заголовком, текстом новости и датой публикации.
- Фабрика `ArticleFactory`, которая генерирует данные с помощью Faker.
- Заполнение базы данными через `DatabaseSeeder`: создаются 20 новостей.
- `ArticleController`, который получает новости из базы и выводит их в хронологическом порядке.
- Страница списка новостей с пагинацией и адаптивной навигацией.
- Именованный маршрут `articles.index` и ссылка на новости в общем меню сайта.

## Модель и таблица новостей

Модель `App\Models\Article` связана с таблицей `articles`. В таблице хранятся:

- `title` — заголовок новости;
- `content` — текст новости;
- `published_at` — дата публикации;
- `created_at` и `updated_at` — даты создания и изменения записи.

## Запуск проекта

Требуются PHP 8.3 или новее и Composer.

```bash
composer install
```

Создайте файл `.env` на основе `.env.example`, настройте подключение к базе данных и сгенерируйте ключ приложения:

```bash
php artisan key:generate
```

Примените миграции и заполните базу тестовыми данными:

```bash
php artisan migrate --seed
```

Запустите локальный сервер:

```bash
php artisan serve
```

Откройте адрес, указанный Artisan (обычно `http://127.0.0.1:8000`).

Для повторного создания таблиц и наполнения базы данными:

```bash
php artisan migrate:fresh --seed
```

> `migrate:fresh` удаляет все существующие таблицы в выбранной базе данных. Используйте команду только для локальной или тестовой базы.

## Тестирование

Запустите тесты проекта:


Feature-тесты проверяют отображение новостей, работу пагинации и заполнение таблицы новостей сидером.
